# Главная

Стартовая страница после входа: сводка по всем разделам, к которым у вас есть доступ.

## Что на ней

- **KPI-карточки** — число серверов онлайн, открытых задач, статей и ближайших событий. Нажмите на карточку, чтобы перейти в раздел.
- **Серверы** — состояние онлайн/офлайн, кольцо занятой памяти, заполненность дисков.
- **Задачи по статусам** — по колонкам досок Jira.
- **Ближайшие события** календаря.
- **Последние статьи** Confluence.

Блок появляется, только если у вас есть право просмотра соответствующего раздела и раздел не выключен администратором (см. страницу «Разделы»).

## Настройка

**Настройки → Главная** — какие блоки показывать и в каком порядке (перетаскиванием). Настройка личная: у каждого пользователя свой набор.
