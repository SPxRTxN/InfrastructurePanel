# Разделы

**Настройки → Разделы** (право `settings.manage`) — выключение ненужных разделов для всех пользователей.

Разделы, которые можно выключить: Серверы и узлы, Топология, Jira, Confluence, Календарь и другие из списка на странице. Выключенный раздел пропадает из меню, виджетов главной и API у всех, данные при этом **не удаляются**: включите раздел обратно, и всё на месте.

Зачем: одна и та же панель годится для основного сервера и для маленькой машины вроде Raspberry Pi, где нужен только мониторинг.

Выключайте разделы осознанно: если выключить «Confluence», это руководство тоже станет недоступно.
