# Confluence

Заметки и статьи. Права: просмотр `confluence.view`, изменение `confluence.edit`.

- **Пространство** — папка верхнего уровня (например, `HOME`, `LAB`). Создаётся внизу главной страницы Confluence; ключ — латиница и цифры, 2–16 символов.
- **Статьи** образуют дерево (слева). **Дочерняя** создаёт статью внутри текущей. Сделать статью дочерней самой себе нельзя.
- **Редактировать** — редактор Markdown с предпросмотром рядом.
- **История** — все версии; любую можно посмотреть и восстановить. Восстановление создаёт новую версию, старые остаются.
- **Поиск** — по заголовкам и тексту.
- **Связанные задачи** — внизу статьи: введите ключ (`HL-1`) и нажмите «Связать». Связь видна с обеих сторон.

При удалении статьи дочерние поднимаются на уровень выше.

## Пространство «Руководство»

Это руководство живёт в пространстве `GUIDE`. Оно создаётся и обновляется автоматически из кода панели. Ваша правка такой страницы сохранится как версия в истории, но при следующем изменении текста в коде страница обновится снова, поэтому свои заметки ведите в других пространствах.

## Шпаргалка по Markdown

| Пишете | Получаете |
|---|---|
| `# Заголовок`, `## Подзаголовок` | заголовки |
| `**жирный**`, `*курсив*` | жирный, курсив |
| `- пункт` или `1. пункт` | списки |
| `[текст](https://…)` | ссылка |
| обратные кавычки вокруг слова, блок между строками из трёх кавычек | код |
| строка с `\|` и строка `\|---\|---\|` | таблица |
| `> цитата` | цитата |

HTML-теги в тексте не выполняются — это защита от XSS, а не ошибка.
