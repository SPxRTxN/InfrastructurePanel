# Сервисы

Раздел **Сервисы** — общий список сервисов всех узлов (файловый менеджер, веб-панели и т. п.) на одной странице.

Права: просмотр `services.view`, изменение `services.edit`. Раздел можно выключить в **Настройки → Разделы**.

- **Список** — плитки: иконка вида, имя, индикатор «доступен / недоступен», узел. Кнопка **Открыть** ведёт на веб-интерфейс сервиса в новой вкладке (если задан веб-адрес). Поиск — по имени.
- **Страница сервиса** — узел (ссылка на него), вид, описание, адрес проверки, статус, время последней проверки и ошибка.
- **Новый сервис** — раскройте «Новый сервис»: узел, имя, вид, тип проверки (`tcp` — `host:port`, `http` — URL), адрес проверки, веб-адрес (только `http://` или `https://`), описание.
- Изменить и удалить сервис можно на его странице. Удаление попадает в журнал.

Проверка доступности выполняется по расписанию вместе с проверкой узлов. Сервисы можно по-прежнему добавлять и из настроек узла.
