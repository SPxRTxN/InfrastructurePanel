# История изменений homelab-agent

Формат: «## X.Y.Z — дата», новые версии сверху. Версия — `homelab_agent/__init__.py`; по ней панель предлагает
узлам обновление. Что умеет агент — [docs/Возможности.md](docs/Возможности.md).

## 0.2.0 — 2026-11-01

Первая публикуемая версия (выходит вместе с панелью 0.5.0).

- **Телеметрия**: CPU, память, разделы дисков (как `df`), температуры, время работы, процессы, службы systemd,
  проверки TCP/HTTP, свои команды-метрики; Windows и BSD — через psutil.
- **Связь**: WebSocket к одной или нескольким панелям, буфер на время обрыва, повтор с паузой; `wss://` с проверкой
  сертификата, `ws://` — только с явным `insecure = true`.
- **Восстановление**: действия только из конфига узла (лимит частоты, таймаут, без shell), автовосстановление.
- **Из панели**: обновление на выбранную версию с самотестом и откатом (сторож), настройки (интервал, сборщики,
  дисплей, WoL, обновление), удаление агента при удалении узла, Wake-on-LAN, VPN (только с `[vpn]` на узле).
- **Дисплей**: OLED SSD1306/SSD1315 128×64 — IP, здоровье, связь с панелями, время работы, защита от выгорания.
- **Установка**: одна папка `/opt/homelab-agent`; `start-agent` (Linux, systemd), `start-agent.ps1` (Windows),
  `push-agent --install` с сервера; перенос старой раскладки; `uninstall-agent`.

## 0.1.0 — 2026-10-31

Первая установка на узлах (Raspberry Pi): сбор метрик, связь с панелью, действия, дисплей.
