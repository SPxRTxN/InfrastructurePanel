# История изменений

Формат: «## X.Y.Z — дата», новые версии сверху. Версия панели — `app/__init__.py`.

## 0.5.0 — 2026-11-02

Первая версия с релизами: у панели появился номер версии (виден внизу меню и в `/healthz`),
а по тегу `vX.Y.Z` на GitHub собираются образ и файлы для установки.

### Что есть в панели
- **Вход и права**: пароли argon2id, сессии, CSRF, блокировка перебора, группы с правами, журнал безопасности.
  Первый вход `admin` / `admin` с обязательной сменой пароля.
- **Главная, Инфраструктура**: серверы и сервисы, узлы с агентами, карта сети (серверы и устройства
  связаны), диски и память, графики за 24 часа, архив удалённого с историей.
- **Агенты** (`homelab-agent` 0.2.0): телеметрия в панель по WebSocket, разрешённые на узле действия
  восстановления, Wake-on-LAN, дисплей OLED. Обновление, откат и настройки агентов — из панели
  («Инфраструктура → Агенты», страница узла); удаление узла удаляет и агента на машине.
- **Карта сети**: связи протягиваются прямо на поле, порты по шаблонам устройств, Wi-Fi пунктиром,
  сегменты-рамки; действия по типу устройства (веб-интерфейс, Wake-on-LAN).
- **Обновление панели — из панели** («Настройки → Обновление»): всем остальным — «технические работы»,
  администратору — ход и лог; при неудаче откат. Выход после 30 минут бездействия.
- **Jira и Confluence**: канбан-доски, статьи в Markdown с историей версий, двусторонние связи;
  руководство пользователя встроено в Confluence панели.
- **Календарь**: события, повторы, напоминания в колокольчике и браузере, сроки задач.
- **Оповещения**: правила, тишина, колокольчик, Telegram и webhook, получатели по группам.
- **Бэкапы и перенос**: бэкапы по расписанию с проверкой восстановления, шифрование (SQLCipher, age),
  экспорт и импорт конфигурации `.hlconf`.
- **VPN**: подписка, сервер, трафик узла через VPN (со сторожем).
- **Установка**: Docker-образ (amd64 и arm64) и нативная установка службой systemd для Raspberry Pi.

### Как обновиться
- **Docker**: впервые — `sudo bash tools/deploy.sh build` (или `deploy.sh pull 0.5.0`): бэкап, выкладка,
  проверка, откат при сбое; заодно ставится служба обновления. Дальше — «Настройки → Обновление» в панели.
  Миграции БД применяются при старте, данные в томе сохраняются.
- **Нативная установка** (Raspberry Pi и др.): скачайте `homelab-dashboard-native-0.5.0.tar.gz` из
  релиза, проверьте `sha256sum -c SHA256SUMS`, распакуйте и выполните
  `sudo ./homelab-dashboard-0.5.0/deploy/native/install.sh --upgrade` — он сам сделает бэкап БД,
  заменит код, применит миграции и перезапустит службу.
- **Агент**: у него своя версия (0.2.0, свой `handoff/homelab-agent/CHANGELOG.md`). Узлы с агентом новой
  раскладки обновляются из панели кнопкой. Узлы со старым агентом — один раз
  `sudo bash tools/push-agent.sh --install user@host …`; новые — `homelab-agent-0.2.0.tar.gz` (Linux,
  `./start-agent`) или `.zip` (Windows, `start-agent.ps1`).
