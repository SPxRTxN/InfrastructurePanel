# Как удалить homelab-agent

## Linux (Debian/Ubuntu/Raspberry Pi OS, Arch, Fedora, openSUSE)
```bash
cd ~/homelab-agent
./uninstall-agent          # спросит подтверждение; без вопроса: ./uninstall-agent -y
```
Что удаляется:
- службы `homelab-agent`, `homelab-agent-guard.timer`, `homelab-vpn` (остановка, отключение, ссылки в `/etc/systemd/system`);
- вся папка `/opt/homelab-agent`: программа и её Python-окружение, конфиг, токены, настройки из панели, состояние, юниты;
- права на действия — `/etc/sudoers.d/homelab-agent` (и `homelab-agent-update` старой установки);
- следы старой раскладки: `/etc/homelab-agent`, `/var/lib/homelab-agent`, `/usr/local/lib/homelab-agent`;
- служебный пользователь и группа `homelab-agent`.

Что остаётся (не трогаем, это система): Python и пакеты ОС, включённый I2C, старые записи системного журнала
(в них нет токенов; уходят сами по ротации journald).

### Из панели
Удаление узла в панели с галочкой «удалить агента с узла» (по умолчанию включена) посылает агенту команду `uninstall`;
агент отвечает и запускает `sudo -n /opt/homelab-agent/bin/uninstall-agent --from-panel`: скрипт без вопросов
передаёт работу отдельной службе `systemd-run` и удаляет всё перечисленное выше. Если узел был офлайн, панель
запомнит это (30 дней) и пошлёт команду при следующем подключении. Выключить на узле: `[remote] uninstall = false`
в `agent.toml`.

Вручную, если скрипта нет:
```bash
sudo systemctl disable --now homelab-agent homelab-agent-guard.timer
sudo rm -f /etc/systemd/system/homelab-agent.service /etc/systemd/system/homelab-agent-guard.service \
    /etc/systemd/system/homelab-agent-guard.timer /etc/systemd/system/homelab-vpn.service \
    /etc/sudoers.d/homelab-agent /etc/sudoers.d/homelab-agent-update
sudo systemctl daemon-reload
sudo rm -r /opt/homelab-agent /etc/homelab-agent /var/lib/homelab-agent /usr/local/lib/homelab-agent
sudo userdel homelab-agent
```

## Windows 10/11, Windows Server
`homelab-agent\uninstall-agent.ps1` → правой кнопкой → «Выполнить с помощью PowerShell» (попросит права администратора).

Что удаляется: задача планировщика `homelab-agent`, `C:\Program Files\homelab-agent` (программа),
`C:\ProgramData\homelab-agent` (конфиг, токен, журнал). Python остаётся — если ставился только ради агента:
«Параметры → Приложения → Python 3.12» или `winget uninstall -e --id Python.Python.3.12`.

Вручную (PowerShell от администратора):
```powershell
Unregister-ScheduledTask -TaskName homelab-agent -Confirm:$false
Remove-Item -Recurse -Force "$env:ProgramFiles\homelab-agent", "$env:ProgramData\homelab-agent"
```
Удаление из панели на Windows не поддерживается (агент объявляет `uninstall` только при раскладке Linux).

## В панели
Токен узла продолжает действовать, пока его не отозвать: **Инфраструктура → Узлы → узел → Удалить**
(или «Новый токен», если узел будет переустановлен). Удаление узла стирает и его историю.

## Каталог с установщиком
`~/homelab-agent` (или куда его скопировал `push-agent`) после удаления можно стереть:
`rm -r ~/homelab-agent` / в Windows — удалить папку `homelab-agent`.
