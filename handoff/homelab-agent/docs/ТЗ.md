# ТЗ: homelab-agent

## Зачем
Собирать с каждого узла домашней лаборатории телеметрию (температуры, нагрузка, RAM, диски, процессы, сервисы,
свои проверки), отправлять её в панели Homelab Dashboard и по запросу панели или по локальному правилу
перезапускать упавшие сервисы. На Raspberry Pi — дополнительно выводить состояние на OLED-дисплей.

Прототип — агент из xcale (C, libsensors, JSON по WebSocket). Перенято: самоописание датчиков в `hello`,
выборки `{датчик: значение}`, регистрация по токену, переподключение, отказ от незашифрованного канала.
**Не перенято:** выполнение скриптов, присланных сервером (это удалённое выполнение кода при взломе панели).

## Требования к ресурсам
- RSS ≤ 30 МБ на Pi 4B, CPU < 1 % в среднем при интервале 10 с.
- Чтение `/proc` и `/sys` напрямую или через psutil; никаких тяжёлых зависимостей.
- Работает без панели: дисплей и локальный журнал продолжают работать.

## Конфиг (`/etc/homelab-agent/agent.toml`, 0600)
```toml
node = "raspberry-pi"            # имя узла; по умолчанию hostname
interval = 10                    # секунд, по умолчанию для всех коллекторов

[[panel]]                        # панелей может быть несколько — они независимы
url = "wss://dashboard.lan/agent/ws"
token_file = "/etc/homelab-agent/token-main"
# ca_file = "/etc/homelab-agent/ca.pem"
# insecure = false

[[panel]]
url = "wss://192.168.1.10:8443/agent/ws"
token_file = "/etc/homelab-agent/token-pi"

[collectors.cpu]                 # пусто = включён с настройками по умолчанию
[collectors.memory]
[collectors.disks]
exclude_fs = ["tmpfs", "devtmpfs", "squashfs", "overlay"]
[collectors.thermal]             # /sys/class/thermal + hwmon
[collectors.processes]
watch = [ { name = "nginx", match = "nginx: master" }, { name = "xray", match = "xray" } ]
[collectors.systemd]
units = ["nginx.service", "docker.service"]
interval = 30
[collectors.checks]
tcp = [ { name = "router", host = "192.168.1.1", port = 80 } ]
http = [ { name = "dashboard", url = "http://127.0.0.1:8000/health", expect = 200 } ]
[collectors.command]             # свои метрики: команда из конфига, вывод — число
items = [ { name = "apt_updates", argv = ["/usr/lib/update-notifier/apt-check", "--quiet"], parse = "first_int", interval = 3600 } ]

[actions.restart_nginx]          # allowlist действий восстановления
argv = ["sudo", "-n", "systemctl", "restart", "nginx.service"]
timeout = 30
limit = "3/h"
# auto = { when = "systemd.nginx.service.active == 0", for = 60 }   # автовосстановление (фаза 4, опция)

[display]
enabled = true
driver = "ssd1306"               # SSD1315 совместим по командам с SSD1306
i2c_port = 1
address = 0x3C
rotate = 0
screens = ["network", "health", "panels", "uptime"]
switch_every = 5
```

## Коллекторы (интерфейс)
```python
class Collector:
    name: str                       # "cpu"
    def __init__(self, cfg: dict): ...   # валидация своей секции, ValueError с понятным текстом
    def sensors(self) -> list[Sensor]:   # описание для hello: id, kind, label, unit
    def read(self) -> dict[str, float]:  # текущие значения; ошибка одного датчика не роняет остальные
```
Реестр: `@register("cpu")`. Интервал — свой у каждого коллектора. Значения — только числа
(состояние сервиса: 1/0; процесс: running 1/0, cpu %, rss байт).
Идентификаторы датчиков: `<коллектор>.<объект>.<метрика>`, например `disks./.used`, `thermal.cpu.temp`,
`systemd.nginx.service.active`.

## Действия восстановления
- Только имена из `[actions.*]`. Неизвестное имя → `action_result {ok:false, error:"unknown action"}`.
- Лимит частоты на действие (`limit`), одно действие одновременно, таймаут, вывод обрезается до 4 КБ.
- Журнал действий локально (journald) и в `action_result`.
- Привилегии: агент работает под отдельным пользователем `homelab-agent`; для перезапуска — строки в
  `/etc/sudoers.d/homelab-agent` ровно на нужные команды (`packaging/sudoers.example`). Агент под root не запускается.

## Дисплей (OLED 128×64, SSD1315, I2C)
- Драйвер `luma.oled` (`ssd1306`), адрес по умолчанию 0x3C. Проверка адреса: `sudo i2cdetect -y 1`.
- Экраны по умолчанию: **network** (hostname, IP основного интерфейса — обязательно), **health**
  (температура CPU, загрузка, RAM, диск /), **panels** (к каким панелям подключён, узлов онлайн/всего — если панель
  прислала сводку), **uptime** (время работы, последнее действие восстановления).
- Если дисплей не найден — предупреждение в журнал, агент работает дальше.
- Против выгорания OLED: сдвиг содержимого на 1–2 px раз в минуту, ночью (настраиваемо) — пониженная яркость.

## Нефункциональное
- Тесты: фикстуры `/proc`, `/sys`, вывода `systemctl`; фейковый WebSocket-сервер; фейковое устройство `luma`
  (`dummy`) с проверкой отрисованного изображения.
- `python -m homelab_agent --once` — один сбор и JSON в stdout (отладка коллекторов без панели).
- `python -m homelab_agent --check-config` — проверка конфига и прав на файлы токенов.
- Логи — в stdout (journald), без токенов.
